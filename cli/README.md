# Patchfly CLI

`patchfly` command-line tool for managing apps, releases, and patches.

## Install

```bash
# From source
cd cli
dart pub get
dart pub global activate --source path .

# Verify
patchfly --version
```

## Commands

```bash
# Auth
patchfly register                # create account
patchfly login                   # sign in
patchfly login --api-key pft_... # use an existing API key
patchfly whoami                  # show current user

# App management
patchfly apps list
patchfly apps create --slug com.acme.app --name "Acme"
patchfly apps get com.acme.app
patchfly apps delete com.acme.app

# API keys (for CI / other machines)
patchfly keys list
patchfly keys create --name "CI server"
patchfly keys revoke <id-or-prefix>

# Releases
patchfly releases list com.acme.app
patchfly releases create \
  --app com.acme.app \
  --version 1.0.0+1 \
  --channel stable \
  --notes "Initial release"

# Patches
patchfly init                    # generate patchfly.yaml
patchfly patch                   # build + upload
patchfly patch --skip-build      # upload existing APK
patchfly patch --rollout 10      # start at 10%
patchfly promote --app com.acme.app --release <id> --patch 1
patchfly rollout --patch <id> --percent 50

# Diagnostics
patchfly doctor
```

## Config

CLI state lives in `~/.patchfly/config.json`:
```json
{
  "server": "https://updates.example.com",
  "token": "eyJ...",
  "apiKey": "pft_...",
  "userEmail": "you@example.com",
  "currentAppId": "uuid",
  "currentAppSlug": "com.acme.app"
}
```

Override server with `PATCHFLY_SERVER` env var.

## patchfly.yaml

Generated by `patchfly init` in your Flutter project:

```yaml
app:
  slug: com.acme.app

defaults:
  channel: stable
  abi: arm64-v8a

build:
  apk_path: build/app/outputs/flutter-apk/app-release.apk
```
